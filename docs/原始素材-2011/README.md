# 2011 原始素材

這裡保存的是 2011 年國中科展《立體四方塊》的原始圖檔，作為紀念。
現代重製版（`web/`）已改用瀏覽器即時繪製的等角縮圖呈現題目形狀，**程式不再引用這些檔案**，
但它們是當年的原物，故移到此處留存。

## 內容

- `prob-1.gif` … `prob-13.gif`：13 個官方題目形狀的示意圖。
- `prob-1-sol.gif` … `prob-13-sol.gif`：對應的解答示意圖。
- `perspective-1.png` … `perspective-13.png`：各題目形狀的立體透視圖。

對應的形狀／解答數等資料仍由 `web/public/data/puzzle-data.json` 保存（程式仍在使用）。
